WPO desde el servidor

Página de prueba del ejercicio de la clase 09 de Servidores (Avanzado).

Caché de usuario

El HTML se revalida en cada visita; el CSS, el JS, las imágenes y las fuentes se guardan un año. Para publicar un CSS nuevo se cambia el parámetro de versión: estilo.css?v=2.

Compresión

Brotli para los navegadores que lo aceptan, gzip para el resto, y nada para los formatos que ya vienen comprimidos: JPEG, WebP y WOFF2.

Caché de servidor

La página de /dinamico/hora.php se genera en cada petición salvo que la sirva la caché del servidor.
