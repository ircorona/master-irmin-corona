CSS Units Guide

Medidas Absolutas (Absolute Units)

These units are fixed and don't change based on other elements:

cm - Centimeters

10cm x 10cm

mm - Millimeters

100mm x 100mm

in - Inches

3.94in x 3.94in

px - Pixels

377px x 377px

pt - Points

285pt x 285pt

(1pt = 1/72 inch - used for print)

pc - Picas

24pc x 24pc

(1pc = 12pt = 1/6 inch - old print unit)

Medidas Relativas (Relative Units)

These units change based on parent elements or viewport:

em - Multiplies parent font size

2em = 2x parent size

rem - Multiplies root font size

2rem = 2x html font size

vh - Viewport Height

50vh = 50% of screen height

vw - Viewport Width

50vw = 50% of screen width

% - Percentage

50% = 50% of parent size
