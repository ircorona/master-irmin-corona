📚 Guía Visual de Selectores CSS

1️⃣ Selector: .class1.class2 (SIN ESPACIO)
.caja.especial {
  background: pink;
  border: 5px solid red;
}
📌 Regla: El elemento debe tener AMBAS clases al mismo tiempo.
Sin espacio entre las clases = mismo elemento.

🔍 Estructura HTML:

<div class="caja">
Solo tiene .caja ❌
</div>

<div class="especial">
Solo tiene .especial ❌
</div>

<div class="caja especial">
Tiene AMBAS clases ✅
</div>

🎨 Código CSS:

.caja.especial {
background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%);
color: white;
font-weight: bold;
border: 5px solid #ff0080;
transform: scale(1.05);
}
→

✨ Resultado Visual:

Solo clase "caja" - sin estilo especial
Solo clase "especial" - sin estilo especial
¡AMBAS clases! - ¡Estilo aplicado!
.caja
+
.especial
=
.caja.especial
2️⃣ Selector: .parent .child (CON ESPACIO)
.contenedor-demo .destacado-demo {
  background: blue;
  color: white;
}
📌 Regla: El elemento con clase .destacado-demo debe estar DENTRO de un elemento con clase .contenedor-demo.
Con espacio entre las clases = relación padre-hijo (descendiente).

🔍 Estructura HTML:

<div class="contenedor-demo">
<div class="destacado-demo">
Dentro del contenedor ✅
</div>
</div>

<div class="destacado-demo">
Fuera del contenedor ❌
</div>
→

✨ Resultado Visual:

Contenedor (padre)
¡Destacado DENTRO del contenedor! ✅
Destacado FUERA del contenedor - sin estilo especial ❌
.contenedor-demo
↳
.destacado-demo
= .contenedor-demo .destacado-demo
3️⃣ Selector: .class1, .class2 (CON COMA)
.rojo-demo, .azul-demo {
  background: purple;
  border: 5px solid gold;
}
📌 Regla: Aplica el MISMO estilo a elementos con .rojo-demo Y a elementos con .azul-demo.
Con coma = selector de grupo (clases independientes).

🔍 Estructura HTML:

<div class="rojo-demo">
Tiene estilo ✅
</div>

<div class="azul-demo">
Tiene el MISMO estilo ✅
</div>

<div class="verde-demo">
No tiene estilo ❌
</div>
→

✨ Resultado Visual:

Elemento con clase "rojo-demo" ✅
Elemento con clase "azul-demo" ✅
Elemento con clase "verde-demo" - sin estilo ❌
.rojo-demo
,
.azul-demo
= Ambos reciben el mismo estilo

4️⃣ Z-Index: Controlando las Capas con Exodia
📌 Concepto: El z-index controla qué elementos aparecen "encima" de otros.
Números más altos = aparecen más arriba (más cerca de ti).
Requiere: position debe ser relative, absolute, fixed, o sticky.

🔍 Estructura HTML:

<header>
z-index: 1000 ⬆️ MÁS ALTO
</header>

<img src="/images/Exodia.webp" class="exodia-flotante">
z-index: 500 ⬆️ MEDIO
</img>

<div class="contenido">
z-index: 1 ⬇️ BAJO
</div>

🎨 Código CSS:

header {
position: relative;
z-index: 1000; /* Siempre visible */
}

.exodia-flotante {
position: fixed; /* Se queda fijo al hacer scroll */
bottom: 20px;
right: 20px;
z-index: 500; /* Debajo del header */
width: 200px;
}

body > * {
position: relative;
z-index: 1; /* Contenido normal */
}

✨ Capas Visualizadas (Vista Lateral):

z-index: 1
📄 Contenido Normal
(Capa más baja)
z-index: 500
🎴 Exodia
Flotante pero respeta el header
z-index: 1000
📱 Header Navigation
💡 ¿Cómo funciona?
  • Header (z-index: 1000) - El menú de navegación siempre está visible y nunca es tapado por nada
  • Exodia (z-index: 500) - Flota sobre el contenido normal pero pasa DEBAJO del header cuando haces scroll hacia arriba
  • Contenido (z-index: 1) - Todo el contenido normal de la página está en la capa base

⚠️ Regla importante: Para usar z-index, el elemento DEBE tener position: relative, absolute, fixed, o sticky. Si tiene position: static (el default), z-index no funciona.

Header (1000) > Exodia (500) > Contenido (1)
🎯 Pruébalo: Mira la esquina inferior derecha de tu pantalla. ¡Ahí está Exodia flotando! Haz scroll hacia arriba y verás cómo pasa DEBAJO del header. Pasa el mouse sobre él para ver el efecto hover.

Medidas Relativas (Relative Units)

⭐ Esta sección tiene las clases "medidas" Y "opacity60" JUNTAS ⭐

Mira el borde morado y el fondo degradado - eso viene del selector .medidas.opacity60

em - Multiplies parent font size

2em = 2x parent size

⭐ Fíjate en el degradado azul y borde amarillo ⭐

rem - Multiplies root font size

2rem = 2x html font size

⭐ Mismo estilo que .em porque están en el mismo selector de grupo ⭐

vh - Viewport Height

50vh = 50% of screen height

vw - Viewport Width

50vw = 50% of screen width

% - Percentage

50% = 50% of parent size
